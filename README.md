# Prajwal Acharya — Portfolio

Software Engineer portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

- Identity: `src/data/site.ts`
- Experience & skills: `src/data/experience.ts`
- Case studies: `src/data/projects.ts`
